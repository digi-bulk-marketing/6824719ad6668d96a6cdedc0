# Bulk Button Pro

Bulk Button Pro by Busineeds India.

## Installation

### Windows
1. Download the latest **`.exe`** installer from the [Releases page](https://github.com/digi-bulk-marketing/6824719ad6668d96a6cdedc0/releases/latest).
2. Run the installer and follow the prompts.
3. Launch **Bulk Button Pro** from the Start menu.

## Updates

Download the newest installer from the [Releases page](https://github.com/digi-bulk-marketing/6824719ad6668d96a6cdedc0/releases/latest) and reinstall.
